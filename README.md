# Heizöl Vorabdisposition

Projektarbeit zur Automatisierung eines Geschäftsprozesses für Heizöl-Bestellungen.

## Ziel
Entwicklung eines prototypischen Systems zur:
- Erfassung von Heizöl-Bestellungen
- automatischen Suche nach Lieferoptionen
- Kommunikation mit dem Kunden
- Übergabe bestätigter Aufträge an die Disposition

## Tech Stack
- BPMN / Camunda 7
- Spring Boot
- React
- PostgreSQL

## Projektstruktur
- `docs/` Projektdokumentation
- `bpmn/` BPMN-Modelle
- `backend/` Backend mit Camunda
- `frontend/` Web-Frontend
