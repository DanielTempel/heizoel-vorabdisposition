# Projektidee

## Arbeitstitel
Automatisierte Vorabdisposition von Heizöl-Bestellungen

## Ziel
Entwicklung eines prototypischen Systems zur:
- Erfassung von Heizöl-Bestellungen
- automatischen Suche nach Lieferoptionen
- Kommunikation mit dem Kunden
- Übergabe bestätigter Aufträge an die Disposition

## Offene Fragen
- Wie erfolgt das Matching von Lieferoptionen?
- Welche Kommunikationskanäle werden im MVP unterstützt?
- Was passiert bei Ablehnung oder ausbleibender Antwort?
