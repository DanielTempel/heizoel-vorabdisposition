\section{Einleitung}

Im aktuellen DISPO-Prozess werden Liefertermine manuell telefonisch mit Kunden abgestimmt. 
Dieser Ablauf ist zeitintensiv, fehleranfällig und schwer skalierbar.

Ziel des Projekts ist die Entwicklung eines digitalen Systems zur automatisierten Planung und Bestätigung von Lieferterminen. 
Die Prozesslogik wird mithilfe von BPMN 2.0 modelliert und durch die Workflow-Engine Camunda ausgeführt.

% ------------------------------------------------
\section{Projektziel}

Das Projekt verfolgt folgende Ziele:

\begin{itemize}
    \item Automatisierung der Lieferterminplanung
    \item Digitale Kundenkommunikation
    \item Verarbeitung von Kundenreaktionen
    \item Workflowgesteuerte Prozessausführung
    \item Verbesserung der Transparenz und Effizienz
\end{itemize}

\begin{itemize}

\section{Akzeptanzkriterien}

Das Projekt gilt als erfolgreich abgeschlossen, wenn:

\begin{itemize}
    \item Liefertermine automatisch verarbeitet werden
    \item Kundenreaktionen korrekt verarbeitet werden
    \item BPMN-Prozesse in Camunda erfolgreich ausgeführt werden
    \item Frontend und Backend korrekt kommunizieren
    \item Alle definierten Muss-Ziele erfüllt sind
\end{itemize}

\section{Erwartetes Ergebnis}

Am Ende des Projekts soll ein funktionierender Prototyp eines workflowbasierten Systems zur automatisierten Lieferterminplanung vorliegen.
